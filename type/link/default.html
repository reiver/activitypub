The following table shows where the ActivityPub Link type an the HTML <link/> element are the same:

Activity Link property HTML <link> attribute Description
href href The target URL/URI/IRI of the linked resource.
hreflang hreflang The language of the linked resource. (Ex: en (English), fa (Persian/Farsi), kr (Korean), etc.)
mediaType type The MIME media type of the referenced resource. (Ex: application/activity+json, image/png, text/html, etc.)
name / nameMap title A human-readable label or title for the target link.
rel rel The relationship type. (Ex: alternative, canonical, license, me, etc.)

The following are properties that the ActivityPub Link type has but the HTML <link/> element does not:

  • height
  • id
  • preview
  • type
  • width
