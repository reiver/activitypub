ActivityPub

ActivityPub is the Social Web protocol used by Mastodon, Misskey, PeerTube Pixelfed, Lemmy, WordPress, and more — which powers the Fediverse.

by Charles Iliya Krempeaux

The name ActivityPub often comes up when people talk about Mastodon, the Fediverse, Pixelfed, and the Social Web. The way that ActivityPub relates to these is — ActivityPub is a computer language spoken by the software running on the servers and clients the makes up the Fedivese and the broader Social Web, such as: Mastodon, Misskey, PeerTube Pixelfed, Lemmy, WordPress, and more.

When a Pixelfed server tells a Mastodon server that user @joeblow@pixelfed.example posted a new photo, it speaks in ActivityPub. When a Mastodon server tells a WordPress server that user @janedoe@mastodon.example replied to a WordPress article, it speaks in ActivityPub. Etc.

A technologist would call a computer language such as ActivityPub a protocol. That (protocol) is another word you will hear used to describe ActivityPub.

ActivityPub Types

Part of ActivityPub is a hierarchical set of types. Types are for the most part defined by the fields their have.

For example, the ActivityPub Link type has the following fields: id, type, height, href, hreflang, name, nameMap, mediaType, preview, rel, width.

Many fields are optional. So, one should probably think of the fields of an ActivityPub types as the fields it could have, rather than what it must have.
