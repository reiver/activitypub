xsd:nonNegativeInteger

n ∈ ℕ0

by Charles Iliya Krempeaux

Some ActivityPub properties have a type of xsd:nonNegativeInteger. As the name suggests, xsd:nonNegativeInteger represents a non-negative integers.

Values for xsd:nonNegativeInteger look like these:

Note that xsd:nonNegativeInteger allows an optional preceding plus sign (“+”) (U+002B). (Although a xsd:nonNegativeInteger in its canonical representation does not allow for a preceding plus sign (“+”) (U+002B))

Note that xsd:nonNegativeInteger allows an optional leading zeros (“0”) (U+0030). (Although a xsd:nonNegativeInteger in its canonical representation does not allow for leading zeros (“0”) (U+0030))

Also note that xsd:nonNegativeInteger do not have an upper bound. Meaning, xsd:nonNegativeInteger can be larger than a unsigned 64-bit integer (uint64) can hold. It can even larger than a unsigned 128-bit integer (uint128), unsigned 256-bit integer (uint256), unsigned 512-bit integer (uint512), etc, can hold.

Canonical Representation Example

xsd:nonNegativeInteger has a concept of a canonical representation.

Some numbers can be represented in more than one way as a xsd:nonNegativeInteger. For example, all of these represent the same number:

  • 12345
  • 012345
  • 0012345
  • 00012345
  • 000012345
  • 0000012345
  • 00000012345
  • 00000000000000000000000000000012345
  • +12345
  • +012345
  • +0012345
  • +00012345
  • +000012345
  • +0000012345
  • +00000012345
  • +00000000000000000000000000000012345

The canonical representation of all these is:

  • 12345

Canonical Representation

The canonical representation of an xsd:nonNegativeInteger has the following properties:

  • Does not have optional preceding plus sign (“+”) (U+002B).
  • Does not have leading zeros.
