xsd:nonNegativeInteger

n ∈ ℕ0

by Charles Iliya Krempeaux

Some ActivityPub properties have a type of xsd:nonNegativeInteger. As the name suggests, xsd:nonNegativeInteger represents a non-negative integer.

Values for xsd:nonNegativeInteger look like this:

  • 0
  • +0
  • 1
  • +1
  • 5
  • +5
  • 123
  • +123
  • 18731
  • +18731
  • 18446744073709551615
  • +18446744073709551615
  • 170141183460469231731687303715884105727
  • +170141183460469231731687303715884105727

Note that xsd:nonNegativeInteger allows an optional preceding plus sign (“+”) (U+002B).

Also note that xsd:nonNegativeInteger do not have an upper bound. Meaning, xsd:nonNegativeInteger can be larger than a unsigned 64-bit integer (uint64) can hold. It can even larger than a unsigned 128-bit integer (uint128), unsigned 256-bit integer (uint256), unsigned 512-bit integer (uint512), etc, can hold.

Specification

The specification where xsd:nonNegativeInteger is defined is at:
