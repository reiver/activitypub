XML Schema Definition (xsd)

xsd:* name-space

by Charles Iliya Krempeaux

ActivityPub makes use of some types from XML Schema Definition (xsd). You do not need to learn all of XML Schema Definition to use ActivityPub. The guides linked to from will give you enough information about XML Schema Definition needed for ActivityPub.

  • xsd:anyURI type
  • xsd:boolean type
  • xsd:dateTime type
  • xsd:duration type
  • xsd:float type
  • xsd:nonNegativeInteger type
  • xsd:string type
