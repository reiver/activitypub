XML Schema Definition (xsd)

xsd:* name-space

by Charles Iliya Krempeaux

ActivityPub makes use of some types from XML Schema Definition (xsd). You do not need to learn all of XML Schema Definition to use ActivityPub. The guides linked to from here will give you enough information about the parts of XML Schema Definition you need for ActivityPub.

  • xsd:anyURI type (ActivityPub guide)
  • xsd:boolean type (ActivityPub guide)
  • xsd:dateTime type (ActivityPub guide)
  • xsd:duration type (ActivityPub guide)
  • xsd:float type (ActivityPub guide)
  • xsd:nonNegativeInteger type (ActivityPub guide)
  • xsd:string type (ActivityPub guide)
